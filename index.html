Mensaje Interceptado

Proyecto en PHP para descifrar los mensajes del Agente 0069.

Descodificador

Escribe el mensaje cifrado (X″) y mira cómo se descifra paso a paso.

Cómo funciona

Paso 1: X″ → X′

Se deshace el desorden de posiciones. Las letras en posiciones pares van al principio y las impares se colocan detrás, en orden inverso.

Paso 2: X′ → X

Se buscan los bloques seguidos que no son vocales (consonantes, espacios y signos) y se le da la vuelta a cada bloque.

Pseudocódigo

Paso 1: X″ → X′ (Miembro A)

FUNCION deshacerIntercalado(texto)
    izquierda = ""
    derecha = ""
    PARA cada posición i del texto (empezando en 0)
        letra = texto[i]
        SI i es par ENTONCES
            izquierda = izquierda + letra
        SINO
            derecha = letra + derecha
    DEVOLVER izquierda + derecha

Paso 2: X′ → X (Miembro B)

FUNCION deshacerInversionConsonantes(texto)
    resultado = ""
    bloque = ""
    PARA cada letra del texto
        SI la letra es vocal ENTONCES
            resultado = resultado + bloque al revés + letra
            bloque = ""
        SINO
            bloque = bloque + letra
    DEVOLVER resultado + bloque al revés

Proceso completo: X″ → X

FUNCION descodificarMensaje(mensaje)
    xPrime = deshacerIntercalado(mensaje)
    xOriginal = deshacerInversionConsonantes(xPrime)
    DEVOLVER xOriginal
